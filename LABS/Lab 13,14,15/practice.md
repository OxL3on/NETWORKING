# Practice Problems

- **Part A — Analyze the address**: Find binary, address class, private/public status, subnet mask, host bits, block size, network address, broadcast address, first/last usable hosts, total addresses, and usable hosts.
- **Part B — Equal-sized subnets**: Calculate the new prefix, mask, block size, capacity, and every subnet's network and broadcast addresses.
- **Part C — VLSM**: Allocate from largest to smallest. Calculate the prefix, mask, network, broadcast, usable host range, and capacity for every department.
- **Part D — Verify**: Check capacity, overlapping ranges, remaining address space, and gateway assignments.
