# Lab 11: Convert IPv4 Addresses Between Decimal and Binary

| Understand how to convert IPv4 addresses between decimal and binary formats.


- IPv4 addresses contain 32 bits, divided into four 8-bit octets.
- Each octet ranges from 0 to 255.
- Binary uses two digits: `0` and `1`.
- Binary place values: `128, 64, 32, 16, 8, 4, 2, 1`.

**Example:**

| Decimal | Binary |
|---|---|
| 192 | `11000000` |
| 168 | `10101000` |
| 1 | `00000001` |
| 10 | `00001010` |

IPv4 Address: `192.168.1.10`

Binary: `11000000.10101000.00000001.00001010`

Each IPv4 octet must be represented using exactly 8 bits. Binary conversion is fundamental to understanding subnet masks and subnetting.
